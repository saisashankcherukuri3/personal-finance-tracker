# Personal Finance Tracker

A command-line application built in Java to track personal income and expenses.

## Features
- Add income and expense transactions by category
- View all transactions in a formatted list
- View a full summary — total income, total expenses, net balance, and spending by category

## How It Works
- `Transaction.java` — OOP class representing a single financial transaction
- `Account.java` — manages a list of transactions using ArrayList and HashMap
- `Main.java` — entry point with a menu-driven interface using Scanner

## Concepts Used
Object-Oriented Programming, ArrayList, HashMap, loops, conditionals
